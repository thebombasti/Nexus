Operational Requirements

1. API Keys (The Lifeblood)

NEXUS is a shell. To make it smart, you need keys. Save these in the Database → APIs section.

  • Google Gemini: Get a free key at AI Studio.
  • YouTube: Create a project in Google Cloud Console and enable Data API v3.
  • Spotify: Register an app in the Spotify Developer Dashboard.

2. Reemo.io (Remote Freedom)

The Remote tab uses Reemo.io. By installing the Reemo streamer on your home PC, you can tunnel through any school/work firewall via NEXUS. It's essentially a high-performance portal to your unblocked machine.

3. CORS & Proxies

If running as a local file, browsers block requests to other sites. NEXUS uses a 45-backend cascade to bypass this. Check the Browser → Log to see which ones are working.

YouTube API

Without a key, ViewTube shows local demo content. Get a free key at console.cloud.google.com.

Device Policy Viewer CHROMEOS

Open chrome://policy → "Export to JSON" → paste the file contents below. Managed (admin-enforced) policies cannot be modified or disabled from a webpage — that's enforced by the OS sandbox. This viewer surfaces them clearly and tags which can/can't be touched.

Extension Viewer

On chrome://extensions, enable Developer mode and click "Pack extension" or copy the visible list. Or paste a JSON array of extension info if exported by another tool. The viewer flags force-installed extensions (those listed in your policy JSON above as ExtensionInstallForcelist).

YouTube OAuth GOOGLE

Create a project at console.cloud.google.com → Enable YouTube Data API v3 → Create OAuth 2.0 credentials. Set the redirect URI to this page's URL (or file:/// if local). Scopes needed: youtube.readonly.

Spotify OAuth SPOTIFY

Create an app at developer.spotify.com/dashboard. Add this page's URL as a redirect URI. Uses PKCE — no client secret needed.

Reality check on managed devices

On a managed Chromebook (school / work), enterprise policies and force-installed extensions are enforced by ChromeOS itself, below the browser layer. A webpage — including this one — has zero ability to read, modify, or "freeze" those policies. The Kill buttons above only act on entries that are user-installed and were never enrolled by an admin. If your account is fully managed, the only paths that actually change anything are admin-side changes, signing out of the managed account, or powerwashing the device. Anything claiming otherwise from inside the browser is lying.
